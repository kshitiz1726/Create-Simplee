# 🐈‍⬛ ClickSimple

# Making the Web Simpler for Everyone

ClickSimple is a local-first Chrome extension that helps people navigate websites, understand web interfaces, and fill out forms with step-by-step guidance.

It is designed to reduce digital barriers for people with disabilities, language barriers, or limited technical literacy, making online experiences more accessible, intuitive, and inclusive.

**Hackathon:** The Bootup Hackathon — Dev Saga  
**Theme:** Build for Everyone

## Who Is ClickSimple For?

ClickSimple is built for everyone, with special attention to India's diverse and multilingual digital community.

- **Indian users:** People who are more comfortable using Hindi or other Indian languages instead of English.
- **People with disabilities:** Users who benefit from clearer website guidance and easier navigation.
- **Non-English speakers:** People who face language barriers while using online platforms.
- **First-time internet users:** People who are still learning how to interact with websites and digital services.
- **Users with limited technical literacy:** People who find complicated forms, buttons, and website instructions difficult to understand.

## Features

- Smart form guidance
- Intelligent website search
- Multi-page guided browsing
- Website navigation explanations
- Embedded-page support
- 17-language interface support, including 10 Indian languages
- English-first language selection
- RTL layouts for right-to-left languages
- Privacy-focused local processing

### Supported Languages

**Indian languages:** Hindi, Bengali, Marathi, Telugu, Tamil, Gujarati, Urdu, Kannada, Odia, and Malayalam.

**Other languages:** English, Chinese, Spanish, Arabic, French, Portuguese, and Russian.

## Installation

1. Download the latest version ZIP.
2. Extract it.
3. Open `chrome://extensions`.
4. Enable Developer Mode.
5. Click Load unpacked.
6. Select the extracted extension folder.
