# 🐈‍⬛ ClickSimple

### Making the Web Simpler for Everyone

ClickSimple is a local-first Chrome extension that helps people navigate websites, understand web interfaces, and fill out forms with step-by-step guidance.

**Hackathon:** The Bootup Hackathon — Dev Saga  
**Theme:** Build for Everyone

## Development Journey

- V1.0.0 — Initial prototype and detailed form guidance.
- V4.1.0 — Evil Larry redesign.
- V4.2.0 — Multilingual support and keyword search.
- V5.0.0 — Fully Resolved Edition.
- V5.1.0 — Guided Browsing Edition.
- V5.2.0 — Embedded Guidance Edition.

## Features

- Smart form guidance
- Intelligent website search
- Multi-page guided browsing
- Website navigation explanations
- Embedded-page support
- 10-language support
- RTL layouts
- Privacy-focused local processing

## Installation

1. Download the latest version ZIP.
2. Extract it.
3. Open chrome://extensions.
4. Enable Developer Mode.
5. Click Load unpacked.
6. Select the extracted extension folder.
